# Тестирование интернет-магазина Hexlet

Репозиторий создан в рамках учебного проекта по ручному тестированию. Основной объект тестирования — SPA-приложение интернет-магазина (products-store.hexlet.app).

## Виды проведенного тестирования

- Функциональное тестирование (каталог, поиск, фильтрация, корзина, оформление заказа).
- Тестирование совместимости (мобильные устройства, браузеры Chrome, Firefox, Safari).
- Проверка работы сети (DevTools).
- Регрессионное тестирование.

## Итоги

В ходе тестирования выявлено несколько дефектов:

- Отсутствует рейтинг на карточках товара
- Отсутствует переход на страницу оплаты после оформления заказа
- Поиск и фильтры работают только в пределах текущей страницы
- Кликабельная область карточки товара не совпадает с видимой рамкой
- Хэштег на странице товара ведёт в некорректную категорию
- Значения в столбце «Количество» не выровнены
- При переключении на английский язык названия товаров не переводятся
- Запрос при оформлении заказа возвращает ошибку 500 (Internal Server Error)
- Кнопка в модальном окне подтверждения заказа обрезана

Все дефекты зафиксированы в файле `bugreports.yml`.
