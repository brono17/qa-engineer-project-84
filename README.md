# Тестирование интернет-магазина Hexlet

Этот репозиторий создан в рамках учебного проекта по ручному тестированию. 
В качестве объекта тестирования выступает SPA-приложение интернет-магазина (products-store.hexlet.app).

## Что было сделано
В ходе работы я изучил функциональные требования к магазину, составил тестовую документацию и провел ручное тестирование основных пользовательских сценариев. Особое внимание уделялось проверке каталога, системы фильтрации, поиска, работы корзины и процесса оформления заказа. Дополнительно была проверена адаптивность интерфейса и его работа в разных браузерах.

## Структура репозитория
- `requirements.yml` — описание функциональных и нефункциональных требований к сайту.
- `test-cases.yml` — тест-кейсы, покрывающие основные сценарии (просмотр карточек, поиск, фильтры, корзина, заказ).
- `bugreports.yml` — найденные в ходе тестирования дефекты с подробным описанием шагов воспроизведения.
- `testing-report.yml` — итоговый отчет о прогоне тест-кейсов (статусы pass/fail).
- `regress-report.yml` — отчет о повторном тестировании после обнаружения бага.

## Итоги тестирования
Большинство проверок пройдено успешно: каталог, фильтры, поиск и корзина работают корректно. 
Однако в процессе оформления заказа был выявлен баг в интерфейсе модального окна — в нем отображается обрезанная кнопка, а также кнопка «Назад», которая не выполняет стандартное действие. Скриншот и подробное описание этого дефекта находятся в файле `bugreports.yml`.
